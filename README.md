One original one-line roast of a gadget used every day (82 characters):

> My robot vacuum spent a year mapping my house and still thinks the rug is a cliff.

The setup is the vacuum's proudest feature — a year spent learning every corner of the house. The punchline is what it learned: the rug is a cliff. A year of mapping, defeated by the cliff sensors mistaking a dark rug for a drop.

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt`.
